# 노래방 노트 (PWA)

홈 화면에 설치하고 오프라인에서도 쓸 수 있는 설치형 웹앱(PWA)입니다.

## 중요: 반드시 웹 서버로 호스팅해야 합니다
`index.html`을 더블클릭해서 그냥 여는 방식(`file://...`)으로는 서비스워커와
"홈 화면에 추가" 기능이 동작하지 않습니다. 브라우저 보안 정책 때문에
**http(s) 주소로 접속해야만** 설치/오프라인 기능이 활성화됩니다.

가장 쉬운 방법 (택 1):

### 1) GitHub Pages (무료, 가장 간단)
1. GitHub에 새 저장소 생성 후 이 폴더(`index.html`, `manifest.json`, `sw.js`, `icons/`)를 업로드
2. 저장소 Settings → Pages → Branch를 `main`으로 설정
3. 몇 분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 접속

### 2) Netlify Drop
1. https://app.netlify.com/drop 접속
2. 이 폴더를 통째로 드래그 앤 드롭 → 즉시 배포 URL 생성

### 3) 로컬에서 테스트만 해보고 싶다면
폴더 안에서 터미널을 열고:
```
python3 -m http.server 8000
```
그 다음 브라우저에서 `http://localhost:8000` 접속 (localhost는 예외적으로 http로도 PWA 기능이 동작합니다)

## 설치 방법
1. 위 방법 중 하나로 배포한 주소에 **스마트폰 브라우저**로 접속
2. 크롬(안드로이드): 메뉴 → "홈 화면에 추가" / 아이폰 사파리: 공유 → "홈 화면에 추가"
3. 홈 화면에 아이콘이 생기고, 탭하면 주소창 없이 앱처럼 전체 화면으로 실행됩니다
4. 한 번 접속한 뒤에는 인터넷이 없어도 실행되고, 저장한 노래 목록도 그대로 유지됩니다

## 데이터 저장 방식
`localStorage`를 사용해 기기(브라우저)에 저장됩니다. 다른 기기와는 자동으로 동기화되지
않으니, 여러 기기에서 쓰고 싶으시면 나중에 서버/로그인 기능을 추가하시면 됩니다.

## 포함된 파일
- `index.html` : 앱 본체
- `manifest.json` : 앱 이름/아이콘/실행 방식을 정의 (설치 가능하게 함)
- `sw.js` : 서비스워커 (오프라인 캐싱)
- `icons/` : 앱 아이콘 (192px, 512px, 애플용)
